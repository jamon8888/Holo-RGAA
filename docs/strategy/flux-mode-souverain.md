# Fiche de flux — mode Souverain (sans Claude)

**Mode Souverain** (PRD **D1**, **D4**, **D6**) : IA `off` ou `byok`, CLI + rapports HTML et page de revue **auto-hébergeable**, **aucun agent tiers requis** (pas de Claude, pas de Codex, pas de computer use). « Sans dépendance américaine » ne s'applique qu'à ce mode. Rien ne sort de l'infrastructure du client sans son accord explicite (NF-1) ; en `byok`, le client utilise sa propre clé Mistral ou un modèle local, mesuré localement (P-3).

## Garantie d'absence de flux vers un éditeur d'agent

Le mode Souverain n'invoque aucun agent tiers : Claude Desktop, Claude in Chrome, Codex et computer use ne sont pas sur le chemin d'audit (D1, D6). **Cible, non implémentée** (aucun code ne lit `RGAA_LLM_MODE` ni ne filtre ces hôtes aujourd'hui ; `rgaa-core/src/provider.rs` ne lit que modèle et URL de base) : le mode sera lu dans la configuration du fournisseur LLM (`RGAA_LLM_MODE` = `off` ou `byok`, défaut `off` sans fournisseur configuré) et affiché par `rgaa status` / en tête de `rgaa audit`. En mode Souverain, la résolution de configuration refusera tout endpoint d'éditeur d'agent ou de routeur pouvant y mener (`api.anthropic.com`, `api.openai.com`, `openrouter.ai`, `generativelanguage.googleapis.com` et sous-domaines ; liste à versionner dans `rgaa-core/src/provider.rs`, à faire valider par le porteur). En `off`, aucun appel modèle ne sera émis. Tant que ce contrôle n'existe pas, la garantie repose sur la configuration choisie par le client. L'agent reste l'appelant du MCP : on ne le contrôle pas depuis ici.

## Points restant à trancher (recherches #403 / #404)

- **Durée de conservation** : 90 j non validée par source primaire, à dériver de la finalité et documenter (art. 5.2, méthode CNIL) ; rien dans les référentiels CNIL sur les captures d'audit.
- **Données de tiers** visibles sur les captures : base légale au client, intérêt légitime (art. 6.1.f) à mettre en balance ; masquage/floutage et purge automatique recommandés (#404 b).
- **`byok`** : la mesure locale des appels est prévue (P-3, F-BILL-8) ; la qualification exacte du flux et les obligations du client envers Mistral restent à documenter.
