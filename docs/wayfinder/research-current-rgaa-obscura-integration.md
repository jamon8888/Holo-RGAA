# Research: current Holo-RGAA ↔ Obscura integration (v0.2.0 pin)

Source ticket: `docs/wayfinder/tickets/02-research-current-rgaa-obscura-integration.md`.
Method: primary sources only — `rgaa-rs/crates/rgaa-obscura/src/*`, `rgaa-orchestrator/src/pipeline.rs`, `rgaa-browser-tools/src/*`, `rgaa-spider`, `rgaa-cli/src/commands/*`, `rgaa-mcp/src/*`, `rgaa-rules/src/*`, repo-root `./obscura` binary, `rgaa-rs/obscura.log`, `install.sh`, `.rgaa/config.yaml`, `README.md` (checked for drift, not trusted).

## 1. Binary launch / version pin

- Repo-root `./obscura` reports `obscura 0.2.0` (`./obscura --version`); `./obscura-worker --version` prints nothing (only `./obscura --version` answered). `rgaa-rs/obscura.log` banner confirms `Headless Browser v0.2.0` + `CDP server: ws://127.0.0.1:9222/devtools/browser`.
- No version-string assertion in Rust code; no `obscura` crate dependency. `rgaa-obscura/Cargo.toml` deps are `tokio, tokio-tungstenite 0.24/rustls, reqwest 0.12, futures-util, base64, sha2, uuid` — the "client" is hand-rolled CDP over websocket, not a generated client.
- Launch seam: `rgaa-obscura/src/lib.rs:ObscuraBridge::start_server` spawns `$binary serve --port $port --quiet` (default binary `"obscura"`, default port `9222`), polls `GET http://127.0.0.1:{port}/json/version` 50×100ms, kills on `stop_server`/`Drop::start_kill`. Readiness key is `webSocketDebuggerUrl` in `get_browser_ws_url`.
- Binary-path resolution: `new()` → `"obscura"` in PATH; `with_binary_path(path)`; `from_env()` reads `RGAA_OBSCURA_BIN` else fallback (`lib.rs:185-192`). Defined but **unused by the hot paths** (see §7 drift).
- Distribution: `install.sh:download_and_install` chmods `obscura`/`obscura-worker` into `$INSTALL_DIR`; `build_from_source` copies repo-root `./obscura` or warns browser automation unavailable; `configure_mcp` writes `"RGAA_OBSCURA_BIN": "${INSTALL_DIR}/obscura"` into `~/.claude/mcp.json`; `verify_install`/`uninstall` cover both binaries. Plugin mirrors: `claude-plugin/.mcp.json`, `rgaa-rs/plugins/rgaa-consultant/.mcp.json` set `RGAA_OBSCURA_BIN: ${CLAUDE_PLUGIN_ROOT}/bin/obscura`.

## 2. CDP client surface (`rgaa-obscura/src/lib.rs`, ~2144 lines)

- Transport primitives: `cdp_issue` (nanotime-mod-1M id, `Message::Text`), `cdp_wait_response` (30s, match id, skip events, surface `error`), `cdp_send` (browser-level) / `cdp_send_session` (with `sessionId`), `cleanup_target` (`Target.detachFromTarget` + `Target.closeTarget` + `ws.close`), `wait_for_load` (poll `document.readyState` every 300ms + observe `Page.loadEventFired` / `lifecycleEvent==load`).
- Per-call target lifecycle: every public method does `Target.createTarget(about:blank|url)` → `Target.attachToTarget(flatten:true)` → work → `cleanup_target`. No persistent session/target reuse; `run_axe_batch` clones `binary_path/port` per task + `Semaphore(concurrency)`.
- Methods: `analyze` (structured contract), `run_guided_test`, `run_axe` / `run_axe_with_script` / `run_axe_batch`, `run_gap_fix` (single via `obscura fetch --eval`) / `run_gap_fix_batch` (single `obscura scrape urls... --eval --concurrency N --format json --timeout 60`, parsed by `parse_scrape_results` expecting `{results:[{url, eval: "<json-string>"}]}`), `extract_page_context` / `extract_page_context_batch` (same scrape path), `run_obscura_fetch` (`obscura fetch <url> --eval <script> --quiet`, returns last stdout line), `eval_js`, `navigate`, `click_element`, `screenshot` (PNG), `get_accessibility_tree` (`Accessibility.enable` + `getFullAXTree`), `type_input`, `press_key` (`Input.dispatchKeyEvent` down+up), `get_tab_order` (JS query of focusables), `assert_state`.
- `analyze` flow (`lib.rs:204-311`): `validate_supported` → fetch axe-source with `timeout_ms` → `run_configured_axe` with retry (`retry_limit`, timeout per attempt) → parse violations → `findings_from_axe` → `NeedsReviewPolicy::Fail` gate → `AnalyzePageResult{findings, evidence, errors, completed=!evidence.is_empty(), igt}`. Browser failures become `AnalyzePageResult::failed` envelope (never clean), classified by `classify_error` into `ObscuraError::page_error` codes.

## 3. axe-core + gap-fix injection

- axe-core: `AXE_CORE_CDN = .../axe-core/4.9.1/axe.min.js`, fetched per `analyze`/`run_axe_batch` via `fetch_axe_source` (reqwest). Injected via `Runtime.evaluate((function(){ <axe_source> })())`, exception → error. Run via `axe.run(<selector-json>?)` with `awaitPromise:true, returnByValue:true`; `validate_axe_result` requires `result.value.violations[]`, else Err (never silent-clean). Configured path adds `Page.navigate` → `wait_for_load` → `Emulation.setDeviceMetricsOverride` (viewport + `mobile: profile=="mobile"`) → cookies → pre-scan actions → inject → run. Legacy `run_axe_core` (used by orchestrator) skips viewport/cookies/pre-scan.
- Mapping: `lib.rs:findings_from_axe` validates payload (`validate_axe_payload`: non-empty id/description, non-empty nodes/target/html), calls `rgaa-rules/src/axe_mapper.rs:AxeMapper::map` (returns `IndexMap<criterion, CriterionResult>`, currently `Result<_, RgaaError>` — IMPLEMENTATION_PLAN's `unwrap_or_default` note is stale), reverse-maps rule→criteria, emits one `Finding` per (node × criterion) with `rule, criterion_id (or "unmapped"), target="a | b", html, failureSummary||description, Fail, impact, help→remediation, source="axe-core"`, sorted by `(id, fingerprint)`.
- Gap-fix: `rgaa-rules/src/gap_fix.rs:GapFixRules::snippets` = 10 static JS snippets (1.1, 1.2, 2.1, 3.2, 6.1, 8.3, 8.5, 11.1, 11.4, 12.7), each returns `JSON.stringify({pass, details, nodes})`; `parse_results` → `CriterionResult{classification: Deterministe, source:"gap-fix"}`. Transport is **Obscura CLI**, not CDP: single-URL via `obscura fetch --eval`, batch via `obscura scrape`. `build_gap_fix_script` / `build_page_context_script` (title/lang/headings/landmarks/images/iframes/media/links/navigation/forms) live in `lib.rs:1498-1547`.

## 4. Cookies / pre-scan actions (`config.rs`)

- `AnalyzeConfig{profile, viewport, selector, pre_scan_actions[≤20, selector≤1024], cookie_references, screenshot, advanced_rule_policy, needs_review_policy, igt_tools, timeout_ms 100-300000, retry_limit ≤5, concurrency, patch_attach_internals}`; `AnalyzeRequest::validate` (URL http/https, viewport 320-7680×240-4320, SameSite=None⇒Secure) + `validate_supported` (profile ∈ default|desktop|mobile; concurrency==1; advanced==Disabled).
- `PreScanAction::{Click, Fill, WaitFor(Visible|Attached|Hidden|Detached)}` executed as `Runtime.evaluate` snippets (`lib.rs:539-591`); `WaitFor` async-polls to `MAX_WAITFOR_TIMEOUT_MS=30s`. `apply_cookies` does `Network.enable` + `Network.setCookie` per `CookieReference{name, value?, domain?, path?, sameSite?, secure?, httpOnly?, expires?}`; `value:None` reads `RGAA_COOKIE_<NAME>` env, missing → `PolicyDenied`; `success==false` → error.
- **Drift (README vs code):** `README.md:397` says cookies are installed **before** `Page.navigate`; code (`run_axe_core_configured:411-437`) navigates + waits + sets viewport **first**, then `apply_cookies`. Cookie-before-initial-request does not hold on the `analyze` path.

## 5. Screenshots / evidence (`evidence.rs`, `results.rs`, `lib.rs:capture_evidence`)

- `capture_evidence`: always captures `document.documentElement.outerHTML` → `EvidenceRef{kind:"dom_snapshot", sha256}` (in-memory hash only at this stage); screenshot iff `ScreenshotPolicy::{None(default)|OnFailure(violations non-empty)|Always}` via `Page.captureScreenshot{format: png|jpeg}`, base64-decode → `EvidenceRef{kind:"screenshot"}`. Missing DOM/screenshot data and bad base64 are hard errors.
- `EvidenceStore::new(root).write(EvidenceArtifact{kind, bytes})` (used only by guided path, root = `temp_dir/rgaa-guided-evidence/<test-id>`): creates dirs, SHA-256 names file (`<hex>.png|json|bin`), rejects non-PNG screenshots by magic bytes, atomic tmp+rename+dir-sync, dedups by existence. `EvidenceRef{kind, path, sha256}` serialized to MCP as `{kind, hash, location}` (`rgaa-mcp/src/tools/analyze.rs:336`).
- `AnalyzePageResult{url, findings, evidence, errors:Vec<PageError>, completed, duration_ms, igt?}`; `failed()` helper; `is_clean_complete = completed && errors.empty && evidence.non-empty`. `ObscuraError` (10 variants: ProcessStartup/CdpTransport/Navigation/Evaluation/Validation/Timeout/Evidence/Json/UnsupportedConfiguration/PolicyDenied) → `PageError{code,message}` wire codes.

## 6. IGT keyboard (`guided.rs`, `lib.rs:run_igt_keyboard`, `results.rs:Igt*`)

- Two seams: (a) inline `run_igt_keyboard` inside `analyze` when `igt_tools∋"keyboard"`: ≤50 synthetic Tabs (`Input.dispatchKeyEvent`), reads `document.activeElement` identity (id else DOM path), flags `keyboard-trap` after 5 repeats on same identity, `no-interactive-elements` if none, returns `IgtResults{keyboard:{status complete|incomplete, issues, igt_elements, terminated_reason}}`; (b) versioned `GuidedTest{id, version, preconditions, steps[], criterion_mapping, evidence_requirements}` + `GuidedStep::{Navigate, AccessibilityTree, PressKey, ClickRef, FillRef, Screenshot, AssertState}` executed by `GuidedTest::run` (mutating-step-must-be-followed-by-observation rule → `InvalidOrdering`; ≤3 retries on Timeout/CdpTransport; `tree`/`screenshot` artifacts persisted; missing required evidence → manual_review).
- `ObscuraGuidedExecutor::connect(bridge)` (own target+session, `current_url`, `accessibility_refs: HashMap<String,u64>`): `PressKey` = keyDown+keyUp + Tab-trap check (activeElement outerHTML unchanged ⇒ `keyboard trap detected`); `ClickRef/FillRef` resolve only **stable** refs (`is_stable_accessibility_reference`: `ax:<u64>` or `ax-role=...;name=...`) via `DOM.resolveNode` → `Runtime.callFunctionOn`; `AccessibilityTree` enables + `getFullAXTree`, registers `ax-role=;name=` aliases, returns `ax:<backendDOMNodeId>` refs + `tree` evidence; `Screenshot` enforces PNG magic; `AssertState` snapshots `{url,title,active_tag,values[]}` for subset-match. `run_guided_test` wires executor+store+close.
- README IGT claims (stable DOM paths, 5-tab trap, incomplete+ExecutionError) match code.

## 7. Orchestrator / spider / MCP / CLI call paths

- `rgaa-orchestrator/src/pipeline.rs:Orchestrator::run/run_batch`: `ObscuraBridge::new()` (NOT `from_env` — `RGAA_OBSCURA_BIN` ignored here) → `start_server` once → `BrowserSession::new(bridge)` → `ToolContext` → legacy per-URL `audit_one`: `bridge.run_axe` → `AxeMapper::map` → `bridge.run_gap_fix(GapFixRules::snippets)` → `GapFixRules::parse_results` → `bridge.extract_page_context` → `na_detection` → Holo3/agent (`run_ia_assiste`, `run_partially_automatable`) → merge axe+gap+holo → fill 106-criterion catalog (Manuel→NeedsReview) → compliance. Uses legacy CDP axe path, **not** `bridge.analyze` (no viewport/cookies/pre-scan/screenshot/IGT/evidence-hash path).
- `rgaa-spider` (`spider_tool.rs:SpiderTool`, Rig `PortableTool"crawl_site"`): workspace **`spider 2.53`** HTTP crawler (`Website::new().with_depth/with_limit/with_respect_robots_txt`, UA `RGAA-Audit-Bot/1.0`, HTML truncated 50k), returns `PageSummary{url, html, links:[], status}`. No Obscura/CDP involvement. **Name collision:** `Cargo.toml:spider 2.53` (web crawler) vs Obscura's own `spider` generated CDP client (not vendored; Holo-RGAA hand-rolls CDP instead). Keep distinct.
- `rgaa-browser-tools` (`session.rs:BrowserSession` wraps `ObscuraBridge`; `ToolContext(Arc<Mutex<Session>>)`; 9 Rig tools `navigate/a11y_tree/eval_js/click/type/press_key/tab_order/screenshot/assert_state` + `BrowserMcpServer::tool_names` skeleton + `ax_tree.rs:AXTree/AXNode`): thin delegates to bridge per-call-target methods. `mcp.rs` is placeholder (`new_placeholder`, no live wiring).
- `rgaa-mcp` (`server.rs`, `tools/analyze.rs`, `main.rs`): `analyze` → `to_domain` (viewport flat-override, pre-scan/cookies/screenshot/igt/timeout/retry mapping; rejects `screenshot.saveTo/inline`; `advanced_rules thorough|standard` collapses to `Disabled`) → `ObscuraAnalyzeService::analyze` → `LazyObscuraBridge::ensure_started` (lazy `start_server` once, mutex-guarded) → `bridge.analyze`. `igt` → `ObscuraGuidedService::run` → `bridge.run_guided_test`. `audit_url` → `OrchestrationService::run_audit` → `Orchestrator::run` (legacy pipeline). Wiring gap: `main.rs:13` builds `ObscuraBridge::new()`, so `RGAA_OBSCURA_BIN` from `install.sh`-generated `mcp.json` is **not honored** unless switched to `from_env()` (same for orchestrator + `rgaa-cli/src/commands/igt.rs:48`).
- `rgaa-cli` (`commands/analyze.rs:run` → `Config::load(.rgaa/config.yaml)` → `resolve_url(--url|--profile|default)` → `Orchestrator::new().run(url, CrawlConfig::default())` → json/table/html; `commands/igt.rs:run` validates `--test` against `config.guided_tests[]`, builds empty-step `GuidedTest{id, version:1}`, `ObscuraBridge::new()`+`start_server`+`run_guided_test`). `crawl_config()` ignores `.rgaa/config.yaml` viewport/timeout/policy content (returns `CrawlConfig::default()`); `Config` covers `url_profiles/viewport_profiles/guided_tests/standards/policy/evidence_dir/remote_endpoint/upload_consent` only.
- Test/manual hooks: `rgaa-rs/test_cdp.js` (playwright-core `connectOverCDP ws://127.0.0.1:9222`, goto example.com), `rgaa-rs/test_obscura.rs` (`ObscuraBridge::new().extract_page_context`), unit tests in `config.rs/results.rs/lib.rs` (validation, error codes, payload guards — no live-browser assertions except one network-gated axe test on port 9244).

## 8. `install.sh` + `RGAA_OBSCURA_BIN` + `.rgaa/config.yaml`

- `install.sh` (487 lines): `--build`/download matrix (`linux-x86_64/darwin-*`; no `linux-aarch64` prebuilt), `PLUGIN_DIR ~/.claude/plugins/rgaa-audit` symlink, `create_default_config` writes `.rgaa/config.yaml` (url/viewport profiles incl. desktop 1000×1080 + mobile 375×812, `guided_tests:[]`, standards wcag+rgai, policy min 80, evidence dir, remote null, consent false) only if absent.
