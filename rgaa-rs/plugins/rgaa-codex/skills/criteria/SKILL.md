# RGAA criteria reference

Use `list_criteria` to retrieve criterion IDs, titles, and classifications when
the MCP server is available. Explain a criterion in plain language and relate
it to the user's example without converting general guidance into a finding.

Distinguish the catalog classification from a test result. A criterion marked
for human review is not automatically a failure or a pass. If the requested
details exceed the tool's catalog output, consult repository documentation or
say what information is not available.
